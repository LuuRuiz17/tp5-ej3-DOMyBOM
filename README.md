# 📝 Lista de Tareas con JavaScript y Bootstrap

Este proyecto es una práctica sencilla de manipulación del DOM (Document Object Model) usando JavaScript, combinada con el uso de Bootstrap para darle un estilo responsivo y moderno a la interfaz.

## 🔧 Tecnologías utilizadas

- HTML5
- CSS3
- Bootstrap 5
- JavaScript

## 🎯 Funcionalidad

- Permite ingresar una tarea a través de un campo de texto.
- Al presionar el botón "Agregar tarea", la tarea se añade a una lista visible en pantalla.
- Cada tarea mostrada en la lista tiene un botón para eliminarla.
- El diseño es responsive, adaptándose a dispositivos móviles, tablets y pantallas grandes.

## 💡 Objetivo del ejercicio

Este ejercicio tiene como objetivo practicar el uso de:

- Eventos del DOM (`submit`, `click`)
- Creación y eliminación dinámica de elementos HTML
- Clases de Bootstrap para diseño responsivo
- Uso básico de JavaScript para gestionar interacción del usuario
